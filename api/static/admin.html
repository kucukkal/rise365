These phrases appear before Ramadan to motivate users based on last year's Taraweeh attendance. Use {count} to insert last year's count.

{count} is required — it will be replaced with the user's actual number. You can only change the words around it.
Example: "MashaAllah! Last year you prayed {count} Taraweeh nights — beat that this Ramadan! 🌙"
